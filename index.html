FAQ

常见问题

关于免费、隐私、大模型与使用方式，你可能想知道的。

秒变爆款是免费的吗？
完全免费且开源（Apache 2.0）。你只需自备所选大模型的 API Key，扩展本身不收取任何费用。
支持哪些大模型？会用到 OpenAI 或 Claude 吗？
支持 Kimi、DeepSeek、Qwen（通义千问）、GLM（智谱）、MiniMax 五家中国大模型，均走 OpenAI 兼容接口。不集成 OpenAI、Claude、Gemini 等境外模型。
我的 API Key 和内容安全吗？
安全。API Key 仅保存在浏览器本地 chrome.storage，生成请求由你的浏览器直连大模型厂商，项目方不设服务器、不收集任何数据。全部代码开源可审计。
可以把视频转成文案吗？
可以。粘贴 YouTube 或 B站 视频链接即可自动抓取字幕并总结改写。B站 字幕需登录后使用；视频无字幕时会提示手动粘贴文稿，因此任意视频都能用。
生成的文案能直接发布吗？
可以。支持一键复制或导出为 txt，每篇自动附带「Made with 秒变爆款」署名水印（可在设置中关闭）。
