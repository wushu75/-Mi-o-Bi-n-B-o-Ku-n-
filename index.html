Get started

Install in under a minute

  1. Download the extension

    Grab the ZIP from the repo (Code → Download ZIP) and unzip it.

  2. Open the extensions page

    Go to chrome://extensions

  3. Turn on Developer mode

    Use the toggle in the top-right corner.

  4. Load unpacked

    Click “Load unpacked” and pick the unzipped TrustExt folder. Pin the shield and open it.

Coming from the Chrome Web Store?

A one-click store listing is planned. Until it's approved, the load-unpacked method above works on every Chromium browser — Chrome, Edge, Brave and more.
